================================================================================
                    BEACON AI - TECH STACK EXPLANATION (SIMPLE GUIDE)
================================================================================

This document explains the exact technology stack used in Beacon AI in simple,
easy-to-understand terms. Anyone can read and understand this guide.

--------------------------------------------------------------------------------
1. FRONTEND (What the user sees and clicks on screen)
--------------------------------------------------------------------------------

* LANGUAGE USED:
  - TypeScript (with React 19 and Next.js 16)
  - HTML & Tailwind CSS v4 (for styling and layout)

* WHY IT WAS USED:
  1. TypeScript prevents bugs: It checks code before running so that typos, 
     missing variables, or broken links never reach the user.
  2. Next.js 16 App Router: It renders pages on the server before sending them 
     to the browser. This means pages open instantly (no loading spinners) and 
     public credential pages (like /verify/[id]) can be shared on LinkedIn easily.
  3. Tailwind CSS: A modern styling tool that lets us build clean Dark Mode and 
     Light Mode buttons and responsive cards without writing thousands of lines 
     of slow, messy CSS.
  4. React 19: Allows fast, interactive components like modals, office-hour 
     booking buttons, and real-time tabs without refreshing the whole browser.


--------------------------------------------------------------------------------
2. BACKEND (What runs behind the scenes on the server)
--------------------------------------------------------------------------------

* LANGUAGE USED:
  - TypeScript running on Node.js (Version 20+)
  - SQL (Structured Query Language) using SQLite ("better-sqlite3")

* WHY IT WAS USED:
  1. Unified Language: Because the backend is also in TypeScript, the frontend 
     and backend speak the exact same language. No translation errors.
  2. Security & Privacy: Sensitive passwords, student vault data, and secret API 
     keys are kept safely on the backend server. The user's browser never sees 
     or leaks private API keys.
  3. SQLite Database ("better-sqlite3"):
     - It stores all data (student profiles, passwords, project scores, mentor 
       bookings) in a single fast file on your disk (data/beacon.db).
     - It requires ZERO external internet connection to an expensive cloud DB.
     - Reading and writing data takes less than 1 millisecond (0.001 seconds), 
       making the entire website lightning fast.
  4. Cryptographic Proof-of-Work: Node.js built-in "crypto" module signs 
     verified projects using SHA-256 HMAC digital signatures (BCN-POW-XXXX) so 
     nobody can fake or tamper with audit scores.


--------------------------------------------------------------------------------
3. API USED (How the AI intelligence works)
--------------------------------------------------------------------------------

* API USED:
  - Groq Cloud API (https://api.groq.com/openai/v1/chat/completions)

* WHY GROQ WAS USED:
  1. Ultra-Fast Speed: Groq uses specialized LPU (Language Processing Unit) 
     chips that process text in 0.08 to 0.15 seconds. It is 5x to 10x faster 
     than standard OpenAI or traditional cloud APIs.
  2. Real-Time Chat: Because it is so fast, the AI Career Coach feels like an 
     instant conversation with zero awkward pauses.
  3. Cost & Privacy: Groq does not train public models on private student 
     vault data, complying with our DPDP 2023 privacy rules.

* WHICH MODELS ARE USED:
  1. "openai/gpt-oss-120b" (Primary Model):
     - A massive, frontier 120-Billion parameter reasoning model.
     - Used for: Deep AI Skills Diagnostic, code repository evaluation, 
       and detailed career roadmap generation.
  2. "openai/gpt-oss-20b" (Speed Model):
     - A 20-Billion parameter high-speed model.
     - Used for: Real-time quick responses, instant interview advice, and 
       fast profile summaries.
  3. "qwen/qwen3.8-27b" (Fallback Model):
     - High-accuracy 27-Billion parameter multilingual model.
  4. Local RAG Fallback Engine:
     - If the user has no internet or runs out of Groq tokens, Beacon has an 
       in-built local AI engine in SQLite that answers questions using the 
       student's real vault data without crashing!
